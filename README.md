# TextiConect: plan de digitalización y convergencia IT/OT

Sitio web del caso práctico "Digitalización y Convergencia IT/OT en TextiConect" (UD1, Digitalización en los sistemas productivos).

Equipo: Marcos Ramos, Gonzalo Redondo, Jaime Ramos y Victor Cerveros.

## Estructura

- `index.html` y las páginas `1-…` a `7-…`: un archivo por cada punto del enunciado.
- `glosario.html`: glosario, fuentes y supuestos del equipo.
- `assets/`: hoja de estilos y script (menú y demostración de seguimiento).
- `fuente/`: contenido de cada página (`src/`) y el script que monta el sitio (`build.py`).

Para cambiar un texto, edita el archivo correspondiente en `fuente/src/` y vuelve a montar las páginas, o edita directamente el `.html` publicado.
